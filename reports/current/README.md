# 目前研究報告

- 聯邦學習_目前研究報告.docx：可編輯 Word 報告。
- 聯邦學習_目前研究報告.pdf：13 頁排版預覽。
- figures/：6 張 PNG 圖及對應 PDF，適合簡報或列印。
- attacker_weight_and_damage.csv：每個設定／seed 的攻擊者樣本占比及損害。
- validation.json：資料核對紀錄與輸入檔案雜湊。

重建：`.venv/bin/python scripts/build_science_report.py`。需 matplotlib、numpy、python-docx 與中文字型。
